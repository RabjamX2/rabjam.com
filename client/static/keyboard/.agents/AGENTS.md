# Workspace Customization Rules

## CRITICAL CHAT FORMATTING RULES (STRICT OVERRIDE)
- **NEVER** output TeX/LaTeX delimiters or math notation (such as `$\rightarrow$`, `\rightarrow`, `\(...\)`, `\[...\]`, or `$$...$$`).
- The chat UI cannot render TeX string literals.
- **ALWAYS** output literal Unicode characters (`→`, `->`, `α`, `β`, `x²`) and plain Markdown code blocks.
