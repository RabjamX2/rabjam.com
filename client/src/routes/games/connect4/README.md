# Connect 4

A modern, responsive Connect 4 game built with Svelte 5. Features single-player mode with multiple CPU difficulty levels (Easy, Medium, Hard) and interactive UI.

## Features
- **AI Opponents**: Play against Easy, Medium, or Minimax Hard CPU engines.
- **Interactive Board**: Smooth animations and turn indicators.
- **Svelte 5**: Built using modern Svelte 5 runes (`$state`, `$derived`, `$props`).

## Quick Start

```bash
# Clone the repository
git clone https://github.com/RabjamX2/connect4.git
cd connect4

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Tech Stack
- Svelte 5
- Vite
- HTML5 / CSS3
